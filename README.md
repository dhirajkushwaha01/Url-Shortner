# 🔗 URL Shortener

A simple and efficient **URL Shortener** built with Node.js and Express.js. It converts long URLs into short, easy-to-share links and redirects users to the original URL.

## 🚀 Features

* 🔗 Create short URLs from long URLs
* ⚡ Fast URL redirection
* 📊 Generate unique short URL IDs
* 💾 Store URL data in the database
* 🔄 Redirect short URLs to original URLs
* 🛡️ Simple and clean backend architecture

## 🛠️ Tech Stack

* **Node.js**
* **Express.js**
* **MongoDB**
* **JavaScript**
* **REST API**

## 🔄 How It Works

1. User enters a long URL.
2. The server generates a unique short ID.
3. The original URL and short ID are stored in the database.
4. User receives a shortened URL.
5. When the short URL is opened, the server redirects the user to the original URL.

### Example

```text
Original URL:
https://example.com/this-is-a-very-long-url

Short URL:
http://localhost:3000/abc123
```
